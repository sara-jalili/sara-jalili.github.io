# Sara Jalili portfolio — GitHub Pages package

1. Replace `YOUR_EMAIL_HERE` in `index.html` with your email address.
2. Replace the generic GitHub and LinkedIn destinations near the bottom of `index.html` with your exact profile URLs.
3. Upload **the contents of this folder** to the repository named `<your-username>.github.io`.
4. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/(root)**.

The site uses only static HTML and CSS, so it requires no installation or build step.
